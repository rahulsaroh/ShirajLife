Infrastructure Overview

gstack is an autonomous browser testing, synthetic UI validation, and documentation pipeline. Built on the lightning-fast Bun runtime, it orchestrates Playwright and Puppeteer headless sessions to test complex multi-page applications, scrape DOM states, and verify accessibility hierarchies.

It integrates direct skill bindings for AI coding agents (such as Claude Code and custom assistants) and automatically renders Mermaid/Excalidraw architecture diagrams into markdown deliverables.

Key Capabilities

  • Headless End-to-End QA: Automates cross-browser journey testing, form validation, and responsive viewport snapshot diffs.
  • AI Agent Skill Runner: Exposes modular terminal actions for autonomous coding agents to interactively inspect and test web UIs.
  • Diagram Synthesis Engine: Converts raw code architectures into high-res SVG and PNG Mermaid/Excalidraw system blueprints.
  • Zero-Overhead Bun Execution: Starts test suites in milliseconds with native TypeScript execution and low memory consumption.

Technical Specifications

Runtime Bun 1.x & Node.js
Browser Engine Playwright / Chromium / WebKit
Diagram Tools @mermaid-js/mermaid-cli
Execution Mode Headless CLI & Parallel Runners
