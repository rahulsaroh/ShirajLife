Trading-App

Flutter Dart Candlestick UI Order Book Custom Painter

Overview

Trading-App is a responsive financial exchange simulator and order execution workbench. Built to stress-test high-throughput state changes and rapid UI re-renders, it demonstrates real-time order placement, position management, and live portfolio margin calculations.

Designed with a bespoke dark-mode interface inspired by institutional Bloomberg and TradingView terminals, prioritizing high data density and zero cognitive clutter.

Key Features

  • Order Book & Depth Chart: Live simulated Bid/Ask order spread with visual liquidity depth bars.
  • Interactive Candlestick Engine: Pinch-to-zoom multi-timeframe charts built with high-performance Flutter CustomPainter rendering.
  • Real-Time PnL Tracker: Automatic mark-to-market position updates factoring simulated slippage, spread cost, and execution latency.
  • Watchlist & Alert Engine: Multi-symbol asset monitoring with configurable price alert thresholds.
