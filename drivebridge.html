Architecture Overview

DriveBridge is a lightweight, cross-platform local network file transfer and phone-to-PC storage bridge. It operates purely within local Wi-Fi / LAN subnets without relying on internet connections, third-party relays, or telemetry servers.

Utilizing high-performance buffered socket streams and automatic UDP multicast beacon discovery, DriveBridge allows seamless multi-gigabyte transfers with sustained wire speeds.

Key Capabilities

  • Zero-Cloud Privacy: Files never touch external servers or public clouds. Data remains 100% within your local hardware network.
  • Automatic Multicast Discovery: Devices discover each other on the local network instantly without manual IP address configuration.
  • Stream Chunking & Checksums: Fault-tolerant buffered chunking with integrity verification ensures zero data corruption during large transfers.
  • Cross-Platform Compatibility: Native support for Windows desktop, Android mobile, and web browser client pairing.

Technical Specifications

Framework Flutter (Dart 3.x)
Transport Layer TCP Raw Socket Streams + UDP Beacon
Platforms Windows Desktop & Android
