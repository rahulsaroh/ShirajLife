AI Gym Mentor

Flutter SQLite Gemini API Offline-First

Overview

AI Gym Mentor is an offline-first fitness logging companion designed to bypass expensive, bloated subscription-based workouts applications. Built with Flutter, it utilizes lightweight local SQLite storage to achieve fast startup times and secure, absolute data isolation.

To deliver modern intelligence offline, the application incorporates a local cache analyzer powered by the Google Gemini API. This module evaluates monthly workout statistics and tracks custom progressive overload benchmarks with zero backend server overhead.

Features

  • Full Local Privacy: SQLite storage holds all training history, user profile parameters, and routines, leaving zero digital footprints on third-party cloud trackers.
  • Offline AI Coaching: A local caching layer interfaces with Gemini, mapping monthly progress reports, noting hypertrophy plateaus, and outputting specific, actionable training corrections.
  • Hypertrophy Curve Mapping: Analyzes volume, reps, and RPE intervals to chart visual progression lines across target muscle groups.
  • Structured Program Customizer: Create, edit, and template multi-week hypertrophy cycles, volume progression scales, and dynamic warm-up intervals.

Technical Specs

Framework Flutter (Dart)
Database SQLite (sqflite)
Intelligence Gemini Pro API
Architecture Offline-First (BLoC Pattern)
