Overview

Mouse Click Utility is a lightweight desktop automation companion built to execute precise, repetitive mouse clicks and macro coordinate actions. Tailored for QA engineers running stress-test UI workflows, data entry automation, and hardware testing rigs.

Engineered with zero third-party bloat, ensuring minimal CPU usage and instantaneous response to hardware kill-switch hotkeys.

Key Features

  • Sub-Millisecond Interval Control: Configurable click delay ranging from high-frequency burst clicks (1ms) to periodic keep-alive intervals.
  • Randomized Anti-Detection Variance: Natural gaussian jitter dispersion to simulate authentic human pointer micro-movements.
  • Global System Hooking: Intercepts low-level keyboard input to trigger instant emergency pause and kill hotkeys without taking window focus.
  • Coordinate Path Record & Replay: Save multi-point click sequences with repeatable step loops.
